[این اپلیکیشن](https://realfavicongenerator.net/)

## Open Graph

به
[bijanprogrammer.com](https://bijanprogrammer.com/)
برید و المنتِ `head`ـش رو کپی کنید و موارد لازم رو تغییر بدید.

[این مقاله](https://www.freecodecamp.org/news/what-is-open-graph-and-how-can-i-use-it-for-my-website/#what-happens-if-i-don-t-have-it)
هم می‌تونه مفید باشه.

[این اپلیکیشن](https://webcode.tools/)
ابزارهای خوبی برای ساخت موارد مربوط به Meta داره.

از
[این اپلیکیشن](https://opengraph.dev/)
استفاده کنید تا بررسی کنید Open Graph درست تنظیم شده یا نه.

:::warning

نمی‌دونم ضروری هست یا نه، اما احتمالاً باید
`prefix="og: http://ogp.me/ns#"`
رو تو تگ `html` بذارید.

:::

:::warning

لینک تصاویر باید Absolute باشه، مثل
`https://bijanprogrammer.com/banner.webp`
وگرنه بعضی ابزارها نمی‌تونن پیدا‌شون کنن.

:::

## Manifest

[MDN](https://developer.mozilla.org/en-US/docs/Web/Manifest)
یه راهنمای جامع برای هر Member از فایل Manifest داره.

برای آموزش پیش‌رفته‌تر (مثلاً برای PWA)، می‌تونید
[مقالهٔ](https://web.dev/articles/add-manifest)
Web.dev
و استفاده کنید.

## Telegram

یه
[Webpage Bot](https://t.me/WebpageBot/)
وجود داره که می‌تونه تلگرام رو وادار کنه Preview وب‌سایت رو آپدیت کنه.
زمانی که تو تلگرام پیش‌نمایش سایتتون درست نمایش داده نمیشه می‌تونید ازش استفاده کنید.
